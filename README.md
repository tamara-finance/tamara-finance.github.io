# האתר של תמרה אביב - ייעוץ משכנתאות

האתר בנוי ב-Jekyll ומתארח בחינם ב-GitHub Pages.

## להוסיף פוסט לבלוג
1. נכנסים ל-https://app.pagescms.org ומתחברים עם חשבון ה-GitHub.
2. בוחרים את האתר, ובתפריט "פוסטים בבלוג" לוחצים **Add an entry**.
3. ממלאים כותרת, כתובת, תאריך, תמונה ותוכן, ולוחצים **Save**.
4. אחרי 1-2 דקות הפוסט מופיע באתר.

המלצות לקוחות מוסיפים באותה מערכת, בתפריט "המלצות לקוחות".

## לשנות פרטי קשר
את הטלפון, המייל, הוואטסאפ והרשתות החברתיות משנים במקום אחד: בקובץ `_config.yml`.

## הטופס
הפניות נשלחות למייל דרך FormSubmit.co. בפנייה הראשונה מגיע ל-office@tamaraaviv.com מייל אימות, וצריך ללחוץ בו על Activate פעם אחת.

## לעדכן SEO
- **כותרת ותיאור של האתר כולו:** בקובץ `_config.yml`, בשורות `title` ו-`description`. התיאור הוא הטקסט שמופיע מתחת לכותרת בתוצאות החיפוש של גוגל.
- **כותרת ותיאור של דף הבית:** בראש הקובץ `index.html`, בשורה `title`.
- **פוסט בבלוג:** במערכת הניהול, בשדות "כותרת" ו"SEO - תיאור לגוגל".
- **גוגל אנליטיקס ו-Search Console:** בקובץ `_config.yml`, בשורות `google_analytics` ו-`google`.

לערוך קובץ ישירות ב-GitHub: פותחים את הקובץ, לוחצים על סמל העיפרון, משנים ולוחצים **Commit changes**. השינוי עולה לאתר תוך 1-2 דקות.
